# 功能验收清单

使用独立测试应用、测试群和合成数据，逐项验证引用路由、隔离和标题行为。测试时关闭其他群历史或长期记忆注入。

1. 仅安装本插件，默认关闭时原聊天连续性不变。
2. 仅启用测试群；普通闲聊、未选中群、排除群和插件指令不建话题。
3. 分别新开 A、B，给出不同虚构口令；交错引用 A/B 原始提问，回答只知道对应口令。
4. 分别引用普通回复、原生非流式卡片、原生流式卡片，确认恢复同一话题。
5. 同群另一位成员引用 A，继续 A 且历史含正确的发言人身份。两人同时追问同一话题，第二轮看到第一轮回答。
6. 私聊 Alice 和 Bob 使用不同口令，引用不可跨用户恢复；其他群、其他机器人同样隔离。
7. 正常重启后恢复原始提问和机器人回复；首次机器人引用查询成功后，后续能命中缓存。
8. 引用安装前的旧消息、普通闲聊、已删除话题或无法读取消息时，收到明确提示且未调用模型。
9. 模型失败、发送失败、生成取消后可引用原始提问重试；同群其他请求不被遗留锁阻塞。
10. 如需测试第三方卡片兼容性，安装对应插件后重复第 3～5 项，验证卡片作为引用消息的兼容性。按钮/表单按交互约定单独验证，不由卡片显示能力推断支持。
11. 检查关闭插件后原有会话选择和连续聊天；生成期间切换配置、强制终止进程的边界按 README 记录。

记录 AstrBot、飞书 SDK、可选卡片插件版本；只记录合成测试数据，不提交真实聊天、密钥和平台生产配置。

## 自动标题验收

- 默认关闭时，新话题保持编号标题。开启后，完成一次问答，刷新对话列表应看到简短标题。
- 引用旧编号话题应补生成标题；再次续聊已命名话题不应重新生成。
- 手动改名、关闭开关、删除话题后，不应被后台结果覆盖或重建。
- 模型失败不影响正常回复、引用续聊和完整聊天历史。
- 中英文混排标题完整显示；超长标题精简后保存，不截断词语。

## 卡片交互续聊

- A/B 交错后从卡片回到 A，包括 B 仍在生成时同一用户继续操作。
- 同群成员共享，跨群、跨用户、跨平台实例和机器人隔离。
- 重复回调只执行一次，新的操作不会因原提问已登记而被忽略。
- 关联丢失、话题删除、归属冲突、非法元数据、引用冲突时停止。
- 关闭范围时忽略约定；只有正文包含类似 JSON 时仍按普通消息处理。
- 普通及流式回复使用真实原提问编号；重启后引用回复无需查询合成编号。
- 生成异常、发送失败、取消和排队取消均释放锁；数据库迁移保留旧关联。
