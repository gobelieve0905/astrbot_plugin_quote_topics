# 引用续聊

引用消息继续原话题，不引用开启新话题。支持群聊共享、私聊隔离、消息关联持久化和自动话题标题。

独立运行，无需安装其他插件。

## 兼容环境

- AstrBot **4.28.0**，Python **3.12+**。
- 飞书（lark）平台，使用 AstrBot 内置 Agent。
- 恢复机器人回复所属的话题，需要飞书应用具备读取消息权限。

## 安装与使用

在 AstrBot 插件管理中选择“从链接安装”，填写：

```text
https://github.com/gobelieve0905/astrbot_plugin_quote_topics
```

1. 打开插件配置，开启**总开关**。
2. 开启群聊或私聊，并选择全部会话或填写指定 ID。所有开关默认关闭。
3. 按原有方式触发机器人：不引用消息时新建话题，引用已登记的提问或机器人回复时继续原话题。
4. 发送 `/话题状态` 查看当前会话是否启用。

| 操作 | 结果 |
| --- | --- |
| 不引用消息，直接提问 | 新建话题，保留旧话题 |
| 引用话题中的提问或机器人回复 | 继续该话题的最新历史 |
| 同群其他成员引用话题 | 共同续聊，保留发言人身份 |
| 私聊引用旧消息 | 仅恢复当前用户在该机器人下的话题 |
| 引用未登记、已删除或无法读取的消息 | 提示无法恢复，不沿用最近话题 |

**不引用发送“再详细一点”也会新建话题。** 想继续讨论，请引用对应消息。
普通闲聊不会创建话题；原有的 @、唤醒词和权限规则继续生效。

## 卡片按钮与表单续聊

交互插件可通过 [卡片交互续聊约定 v1](CONTINUATION_PROTOCOL.md) 将按钮或表单操作交给本插件，恢复原卡片对应的话题。支持独立操作去重、同群成员共同续聊，以及引用交互后的机器人回复继续讨论。

这是插件间约定，不是 AstrBot 已有标准。交互插件需要在事件入队前提供可信元数据，并遵守真实消息回复目标的约定；仅安装本插件不会自动为其他卡片增加按钮功能。没有交互插件时，普通引用续聊与不引用新开仍可独立使用。

## 自动话题标题

开启**自动总结话题标题**后，插件会在话题已有问答记录时后台生成简短标题，刷新 AstrBot 对话列表即可查看。

- 每个话题成功生成一次；手动修改过的普通标题会保留。
- 旧编号话题在下次引用续聊时补生成，不批量处理其他来源的无标题对话。
- 使用当前会话的模型及备用模型配置，额外消耗模型额度；超长标题最多再调用一次模型精简。
- 标题优先24字符以内，最长48字符，完整保存词语。失败时保留原名，下次续聊重试。
- 单模型默认等待120秒，可调整为20–240秒。后台生成不阻塞正常聊天。

此功能只修改标题，不发送总结消息，也不压缩聊天历史。关闭后保留已生成的标题。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 总开关 `enabled` | 关闭 | 启用引用续聊 |
| 平台实例范围 `platform_ids` | 空列表 | 留空表示全部实例；填写 AstrBot 平台实例 ID |
| 群聊 / 私聊开关 `enable_group` / `enable_private` | 关闭 | 分别启用 |
| 全部群聊 / 私聊 `group_all` / `private_all` | 关闭 | 关闭时仅启用指定列表 |
| 指定群聊 `group_ids` | 空列表 | 飞书聊天 ID，`oc_` 开头 |
| 指定私聊 `private_ids` | 空列表 | 用户 Open ID，`ou_` 开头 |
| 排除列表 `excluded_group_ids` / `excluded_private_ids` | 空列表 | 优先于全部和指定列表 |
| 自动标题 `auto_topic_title` | 关闭 | 自动概括话题标题 |
| 标题等待时间 `auto_topic_title_timeout` | 120秒 | 单个模型的等待上限 |

“全部”关闭且指定列表为空时，不启用任何会话。未启用的会话保持 AstrBot 原有行为。

## 使用限制

- 安装前未登记的消息无法恢复话题。主动发送或未保留回复关系的消息无法恢复；卡片按钮和表单需由交互插件接入上述约定。
- 不支持 Dify、Coze 或绕过内置 Agent 管道自行调用模型的插件。
- 群聊记忆等插件注入的额外上下文不属于本插件的隔离范围。请避免与其他话题路由插件同时使用。
- 同群请求按顺序处理，不同群和私聊可并行；不支持多个 AstrBot 进程共享插件数据库。
- 请在当前请求完成后切换模式或卸载插件，避免在生成过程中切换或删除对话。

## 数据与备份

消息关联保存在 `data/plugin_data/astrbot_plugin_quote_topics/index.sqlite3`，聊天正文仍由 AstrBot 保存。重启和更新会保留关联记录。

请一起备份 AstrBot 数据和插件数据，使用 SQLite 在线备份或停止服务后复制。插件不会自动清理历史和索引；删除话题后无法恢复其内容。
